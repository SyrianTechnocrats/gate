# بوابة الحضور — التكنوقراط السوريون

تطبيق ويب لتسجيل الحضور بمسح رمز الاستجابة السريعة، يعمل دون إنترنت بعد فتحه مرة واحدة، ويُعاد استخدامه لكل فعالية.

| الصفحة | الاستخدام |
|---|---|
| `index.html` | تطبيق المسح على هواتف الباب: مسح، تسجيل يدوي، سجل وإحصاءات، تصدير إكسل ودمج أجهزة، مزامنة اختيارية مع جدول جوجل |
| `admin.html` | الإدارة: بيانات الفعالية والفئات، استيراد الأسماء من إكسل، التصميم وتحديد مكان الاسم والرمز، ملف الطباعة، صور البطاقات، الإرسال بواتساب والبريد، النشر |
| `badge.html#t=…` | صفحة البطاقة الشخصية التي يصل رابطها لكل مدعو |
| `event.json` | بيانات الفعالية المنشورة (الأسماء دون أرقام الهواتف أو البريد) |
| `templates/` | خلفيات التصميم المرفوعة من صفحة الإدارة |

## دورة كل فعالية
1. صفحة الإدارة ← «الفعالية»: الاسم، الرمز الجديد، التاريخ، مقاس البطاقة.
2. «الأسماء»: استيراد ملف الإكسل أو الإضافة والحذف يدوياً.
3. «التصميم»: رفع خلفية الوجه أو الوجهين، ثم سحب مربعات الاسم والرمز إلى مكانها.
4. «النشر»: نشر التغييرات (رمز وصول جيت هب بصلاحية المحتويات على هذا المستودع).
5. «البطاقات والطباعة»: ملف طباعة واحد بعلامات القص، وصور لكل شخص.
6. «الإرسال»: واتساب أو بريد لكل شخص برابط بطاقته.
7. يوم الفعالية: افتح تطبيق المسح على الهواتف وهي متصلة بالإنترنت مرة واحدة، فتُحمَّل القائمة الجديدة ويبدأ سجل نظيف.

رمز الفعالية مكتوب داخل كل رمز استجابة، فتُرفض بطاقات الفعاليات السابقة عند الباب. أرقام الهواتف والبريد تبقى في متصفح جهاز الإدارة فقط.

المكتبات المضمّنة في `lib/`: jsQR، SheetJS، qrcode-generator، jsPDF، JSZip، PDF.js، وخطّا Cairo وTajawal.
